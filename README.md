### 🧬 Research

**Undergraduate Thesis — Computational & Theoretical Neuroscience Lab (Dr. Lyle Muller, Western University)**

Benchmarked four hyperparameter optimization frameworks (Optuna TPE, CMA-ES, Nevergrad NGOpt, Differential Evolution) for training Structured State Space Models (S4) — the first empirical comparison of HPO methods for SSM training.

My broader interest is in the overlap between SSMs and biological RNNs: SSMs were built to model long-range temporal dependencies efficiently, which makes them a useful computational lens for thinking about how real neural circuits handle memory and timing.
